# 젤다의 성장일기

릴리화이트 크레스티드 게코 **젤다**의 주차별 성장 기록.
사진 한 장, 잰 날짜, 몸무게, 피딩·청소 요일, 메모를 한 주에 한 줄씩 남기고,
4주가 모이면 A4 한 장짜리 PDF로 뽑을 수 있습니다.

---

## 인터넷 주소로 만들기 (GitHub Pages)

한 번만 하면 됩니다. **계정 만들기와 로그인은 직접 하셔야 합니다.**

### 1. GitHub 계정 만들기

<https://github.com/signup> 에서 가입합니다. 무료입니다.

### 2. 저장소(repository) 만들기

1. 로그인한 뒤 우측 상단 **＋** → **New repository**
2. **Repository name**: `zelda` (원하는 이름으로 해도 됩니다)
3. **Public** 을 선택 — 무료 GitHub Pages는 공개 저장소에서만 됩니다
4. **Create repository**

> 공개되는 건 **이 앱의 파일들**(index.html, 젤다 그림 등)뿐입니다.
> **일기와 사진은 절대 여기 올라가지 않습니다.** 그건 폰 안에만 있습니다.

### 3. 파일 올리기

1. 만들어진 저장소 화면에서 **uploading an existing file** 링크를 누릅니다
2. 이 폴더 안의 파일을 **전부 끌어다 놓습니다**:

   ```
   index.html
   manifest.webmanifest
   sw.js
   zelda-sticker.png
   zelda-head.png
   icon-192.png
   icon-512.png
   icon-maskable-512.png
   favicon-64.png
   ```

   (`.claude` 폴더와 이 README는 올리지 않아도 됩니다)
3. 아래 **Commit changes** 를 누릅니다

### 4. Pages 켜기

1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. **Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 를 `main` / `/ (root)` 로 고른 뒤 **Save**
3. 1~2분 기다렸다가 새로고침하면 주소가 나옵니다:

   ```
   https://<내아이디>.github.io/zelda/
   ```

### 5. 폰 홈화면에 붙이기

그 주소를 폰에서 열고,

- **아이폰(Safari)**: 아래 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)**: 우측 위 ⋮ → **홈 화면에 추가**

젤다 아이콘이 생기고, 앱처럼 전체 화면으로 열립니다. 비행기 모드에서도 열립니다.

## 고칠 때

`index.html` 을 고친 뒤 GitHub 저장소에서 같은 파일을 다시 올리면
(**Add file → Upload files** → 덮어쓰기 → Commit) 1~2분 뒤 반영됩니다.

폰에서 옛날 화면이 그대로면, 브라우저를 완전히 껐다 켜 주세요.

## 기록은 어디에 있나요

**폰 브라우저 안(IndexedDB)** 에 있습니다. 서버로 올라가지 않습니다.

| | |
|---|---|
| 좋은 점 | 공짜, 빠름, 인터넷 없어도 됨, 아무도 못 봄 |
| 주의할 점 | **그 폰 그 브라우저에서만** 보입니다 |
| | 브라우저 데이터를 지우거나 폰을 바꾸면 **사라집니다** |

그래서 앱 안에 **백업** 버튼이 있습니다.

- **내보내기** — 기록과 사진을 통째로 담은 `.json` 파일 하나를 내려받습니다.
  구글 드라이브나 메일에 보관해 두세요. **한 달에 한 번쯤** 권합니다.
- **불러오기** — 새 폰에서 그 파일을 고르면 그대로 되살아납니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 (화면 + 기능 + 저장). 이거 하나가 본체입니다 |
| `sw.js` | 오프라인에서도 열리게 하는 캐시. 기록은 여기 들어가지 않습니다 |
| `manifest.webmanifest` | 홈화면 아이콘·앱 이름 설정 |
| `zelda-sticker.png` | 젤다 캐릭터 (전신) |
| `zelda-head.png` | 젤다 캐릭터 (얼굴) |
| `icon-*.png`, `favicon-64.png` | 홈화면·탭 아이콘 |

바꾸고 싶은 값은 `index.html` 안 `<script>` 맨 위에 모여 있습니다.

```js
const PET  = { born:"2026-07-05", adopted:"2026-09-14" };
const GOAL = 15;        // g — 아성체 기준
const PER_SHEET = 4;    // A4 한 장에 몇 주를 넣을지
```

## 주차 계산 기준

- 주는 **월요일**에 시작합니다.
- 그 달 **1일이 속한 주가 1주차**입니다.
- 예: 2026년 9월 14일 → **26년 9월 3주차** (9.14 ~ 9.20)

잰 날짜를 바꾸면 기록이 그 날짜가 속한 주차로 자동으로 옮겨집니다.
